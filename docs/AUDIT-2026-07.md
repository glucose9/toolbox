# barokit.com 전 도구 감사 보고서

- **대상**: 276개 도구 / 265개 컴포넌트 (32,235줄)
- **방법**: 24개 도메인 배치로 전 파일 정독 리뷰 → 배치별 적대적 검증(코드 재추적 + 수식 독립 재계산) → 확정분 수정 → 빌드·배포 검증
- **2026 세법·공휴일 기준**: 웹 검색으로 출처 확인한 팩트시트를 세법 도구 검증의 단일 기준으로 사용

## 집계

1차 치명적·높음, 2차 보통, 3차 낮음까지 **확정 273건 전 등급을 조치 완료**했다.

보류한 3건은 근본적으로 모호하거나 라이브러리 한계로 최소 수정이 불가능한 것들이다:
모스 부호 한글 디코드(같은 부호가 영문·한글 양쪽에 매핑되어 언어 선택 UI 없이 판별 불가),
JSON↔XML 단일 원소 배열 왕복(XML에 배열 개념 없음),
영상 병합 시 무음 입력 혼재(ffmpeg.wasm에 ffprobe가 없어 입력별 오디오 유무 탐지 불가 —
무음 전환 사실을 사용자에게 통지하는 것으로 대체).

  - 나머지는 발현 조건이 환경 의존이어도 손해 없는 방어적 수정(가드·에러 표시·리스너 정리)으로 처리

### 4차 라운드에서 새로 발견된 프로덕션 버그

`likely` 건을 파헤치던 중 **next-intl의 실제 동작을 실측**해 감사가 놓친 렌더 파손을 찾았다.
next-intl은 HTML 태그가 포함된 메시지를 `t()`로 호출하면 FORMATTING_ERROR를 내고
번역문 대신 **메시지 키 문자열**을 반환한다. 그 값이 `dangerouslySetInnerHTML`로
주입되고 있어, 9개 도구 11곳의 안내 문구 자리에 `toolUI.wage-converter.note` 같은
개발자용 키가 ko·en·ja·zh 4개 로케일 전부에서 그대로 표시되고 있었다.
(감사 정찰 단계에서는 이 패턴을 "번역자 제어 문자열이라 저위험 XSS"로 분류했으나,
실제 증상은 XSS가 아니라 렌더 파손이었다.)
→ `t.rich()` 전환으로 수정, 태그 메시지 21개 전부가 `t.rich`로 호출되는 것을 대조 확인.

아래 목록의 `수정됨` 표시는 1차 라운드(치명적·높음) 기준이다. 2·3차 라운드에서
보통·낮음까지 처리했으므로 현재는 표시와 무관하게 확정 273건 전부가 조치된 상태다.

### RealEstateTaxTool (real-estate-tax) — 수정됨

- **양도세: holdMonths < 12 조건이 항상 참 → 모든 비면제 케이스에 70% 단기세율 적용**
  - 재현: `양도차익 100,000,000 / 보유 3년 0개월 / 1주택 체크 해제` → 기대 `3년 이상 보유 → 기본세율 경로. 과세표준 = 100,000,000 − 장특공 6% (6,000,000) − 기본공제 2,500,000 = 91,500,000. 도구 자체 로직대로라도 91,500,000 × 0.3` / 실제 `rate = 0.7 → 양도세 91,500,000 × 0.7 = 64,050,000, 지방세 6,405,000, 합계 70,455,000. 3년이든 15년이든 동일하게 70%.`
- **양도세 기본세율에 누진공제 미적용 (한계세율을 과표 전체에 곱함)**
  - 재현: `과세표준 91,500,000 이 기본세율 경로에 도달했다고 가정 (양도차익 1억, 3년 보유, 다주택)` → 기대 `91,500,000 × 35% − 15,440,000 = 16,585,000 (지방세 포함 18,243,500)` / 실제 `91,500,000 × 0.35 = 32,025,000 (지방세 포함 35,227,500) — 약 1.9배 과대`
- **재산세: 공정시장가액비율(60%) 미적용 + 누진구조 없이 최고구간 세율을 전액에 플랫 적용**
  - 재현: `공시가격 300,000,000 (기본값)` → 기대 `과세표준 = 3억 × 60% = 1.8억 → 60,000 + 90,000,000×0.15% + 30,000,000×0.25% = 270,000원` / 실제 `300,000,000 × 0.25% = 750,000원 (약 2.8배 과대)`
- **취득세 1주택 6~9억 구간을 누진이 아닌 플랫 2%로 계산**
  - 재현: `취득가액 700,000,000 / 주택 / 다주택 아님` → 기대 `세율 (7×2/3−3)% ≈ 1.6667% → 취득세 본세 약 11,666,667원` / 실제 `세율 2% → 14,000,000원 (약 233만원 과대; 8.99억이면 반대로 2% vs 2.99% 과소)`
- **다주택 취득세 8%/12% 를 주택 수가 아닌 '가격 6억' 기준으로 분기**
  - 재현: `조정지역 2주택자가 700,000,000 주택 취득 (isMulti 체크, 가격 7억)` → 기대 `2주택 중과 8% → 56,000,000원` / 실제 `가격 > 6억 → 12% → 84,000,000원 (반대로 3주택자가 5억 주택 취득 시 8%로 과소)`
