# 디스콰이엇 프로덕트 등록 초안

> 게시 위치: https://disquiet.io → 프로덕트 만들기. 로고: /favicon 또는 OG 이미지 사용. 스크린샷: HWP 뷰어, HWP→PDF 배치, PDF 합치기 화면 3장 권장.

## 프로덕트명
바로킷 (barokit)

## 한 줄 소개 (50자 내외)
HWP·PDF·이미지·영상을 브라우저 안에서 바로 변환 — 파일이 서버로 올라가지 않는 파일 도구

## 카테고리
생산성 / 유틸리티

## 설명

바로킷은 파일을 **업로드하지 않고** 다루는 온라인 도구입니다. HWP 열기·PDF 변환·텍스트 추출·HWPX 변환, PDF 합치기·분할·압축·암호 해제, HEIC → JPG, 이미지 압축·리사이즈·배경 제거, 영상 압축·MP3 추출·GIF 변환까지 모두 브라우저 안에서 처리됩니다.

**왜 만들었나**
한컴이 없는 맥에서 공문서를 열고, 은행 명세서 PDF 암호를 풀고, 아이폰 사진을 워드에 넣는 일이 매번 "어딘가에 업로드"를 요구하는 게 싫었습니다. 이력서·계약서·명세서는 올리고 싶지 않은 파일이니까요.

**특징**
- 설치·가입·워터마크 없음
- 파일이 기기 밖으로 나가지 않음 (WebAssembly로 HWP 파서·ffmpeg·AI 배경 제거 모델이 브라우저에서 실행)
- HWP는 뷰어·PDF·텍스트·HWPX 한 세트, 여러 파일 일괄 변환 + ZIP
- HWP → PDF는 미리보기와 동일한 글꼴로 출력 (Noto KR 서브셋 임베딩)

**만든 사람**
DGIST 학부생 1인 개발. 문서·파일 도구를 계속 다듬는 중이고, 어떤 파일이 안 열리는지 알려주시면 실제 파일로 검증해서 고칩니다.
